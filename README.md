# Rentcalculator-
This program calculates how much each person in a shared house needs to pay by dividing total expenses equally.

Inputs it takes:

Total monthly rent

Total food ordered

Total electricity bill

Charge per unit (for electricity)

Number of people sharing the house

How it calculates:

Calculates the total electricity bill: electricity_spend × charge_per_unit

Adds up all expenses: rent + food + total_electricity_bill

Divides the total by the number of people: total ÷ person

Example:

Rent: 1200

Food: 300

Electricity bill: 150

Charge per unit: 2

People: 4

text
Total electricity bill = 150 × 2 = 300
Total expenses = 1200 + 300 + 300 = 1950
Each person pays = 1950 ÷ 4 = 487.5
